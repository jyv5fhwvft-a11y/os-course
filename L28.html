• Step 1 & 2: User Input & Security Vetting RING 3 ➔ RING 0

The user triggers an event. The system traps execution into high-privilege Kernel Mode, passing the request to the Access Control Matrix to authorize the protection domain.

💻 Real-World Application Example: Clicking a file icon inside Google Chrome forces the kernel to read your account token bits, verifying you have explicit 'read' permission before opening the path.
• Step 3 & 4: Process Creation & Memory Mapping PCB + MMU VIRTUALIZATION

The kernel ref allocates a new Process Control Block (PCB) diary, issues a unique PID, and commands the MMU to slice up virtual 4KB pages.

💻 Real-World Application Example: The OS forks a new application window room, carving out independent Stack, Heap, and Data segments inside your RAM chips while initializing an empty Page Table tracking layout.
• Step 5 & 6: File System Retrieval & Storage I/O VFS + DIRECT MEMORY ACCESS

The Virtual File System reads the parent directory to find the target Inode Number, tracking down direct and indirect block pointers on physical hardware sectors.

💻 Real-World Application Example: The storage controller instructs the Direct Memory Access (DMA) chip to pump raw file bytes straight into the allocated RAM frames without taxing the core CPU registers.
• Step 7: Continuous Scheduling & Execution ROUND ROBIN / PREEMPTION

The process state flips to Ready. The Round Robin scheduler dispatches it onto an active CPU core chip, managing continuous timer interrupt context switches.

💻 Real-World Application Example: The application runs line-by-line in User Mode, while the kernel rapidly saves and restores register states inside the PCB diary to share processor turns fairly with Discord or Spotify.

1. Shell Syscall Trap (strace)

The user types a file command. The terminal utility calls a system intercept, trapping execution into Kernel Mode and printing a live diagnostic trace of system calls.

2. Metadata Inode Resolution

The kernel traces the openat() syscall down to the file system index table, verifying user authorization rights and resolving the physical cylinder sector coordinates.

3. Memory Page Fault Thaw

The CPU attempts to execute the newly loaded code pages. It discovers the Present Bit equals 0, triggers a normal Page Fault exception trap, freezes threads for a microsecond, and loads the data from disk into RAM frames.

4. Context-Switched Runtime Execution

The process state marks as Running. The hardware clock ticks continuously, triggering thousands of microsecond context switch saves to balance hardware processing power.

warning
ACADEMIC PITFALL WARNING

Do not think the Operating System is a background program that runs continuously alongside your apps! The OS is an event-driven referee library. It sleeps while your application processes execute in User Mode, waking up ONLY when an interrupt, system call trap, or fault occurs to enforce order and coordinate hardware access!
